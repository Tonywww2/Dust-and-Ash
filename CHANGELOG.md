# Dust and Ash 0.2.2

- Added four tiers of Centrifuge Accelerators. Adjacent centrifuges process recipes in 65%, 35%, 15%, or 10% of the original time; only the strongest adjacent accelerator applies.
- Added the Automatic Milling Recycler, which collects scrap from disabled cells of the milling machine directly behind it. Includes a configurable 5x5 grid and 18 inventory slots with item automation on all sides.
- Added crafting recipes, scrap item tags, English and Chinese descriptions, and guidebook entries for both machines.
- Added machine models aligned to Minecraft's 16-unit block grid and consistent texture scale.
- Tier II accelerators require one Ash Steel Structural Component. Recycler grid buttons have no hover highlighting or tooltips.

Available for Minecraft 1.20.1 Forge and Minecraft 1.21.1 NeoForge.
