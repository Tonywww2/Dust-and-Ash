裂变控制器 UI 概念

统一以 197×192 游戏像素验证。所有版本都保留热量、中子、能量、效率、单元数量、结构尺寸、中子槽与完整玩家背包。

A. 工业安全面板

INDUSTRIAL / LOW RISK

灰钢、警戒黄与独立三色状态条。信息层级最接近现有机器，适合强调“可维护设备”而非魔法装置。

实现：低

B. 科研诊断台

LAB / HIGH CLARITY

浅色陶瓷与冷灰蓝，强调测量和校准。数字最易扫读，也最适合补充悬停提示与状态告警。

实现：低

C. 复古 CRT 终端

PHOSPHOR / DISTINCT

深色磷光屏、点阵边框与扫描线。辨识度最高，但需要同步调整文字颜色，避免与其他机器 GUI 割裂。

实现：中

D. 核心监视器

CORE / HIGH IMPACT

用同心核心仪表作为第一视觉信号，状态条负责精确读数。最有“终局机器”感，需要新增环形仪表贴图。

实现：中高
